# Demo photos

Drop your own photos here to use them in the `/demo` chat. They take priority over the online sample photos.
File name = photo key (`.jpg`, `.jpeg`, `.png` or `.webp`), e.g. `south_indian.jpg`, `pizza.jpg`.

Keys: south_indian, dosa, pizza, chai, kebab, tandoori, biryani, burger, restaurant,
dental, haircut, spa, salon, yoga, gym, pharmacy.

Keep each file under ~300 KB (about 1200 px wide is plenty).
