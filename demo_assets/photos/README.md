# Demo photos

The demo shows real, freely licensed photos from Wikimedia Commons (listed in `COMMONS` in `demo_ui.py`, credited
under each photo). The `.svg` files here are original illustrations (`scripts/make_demo_art.py`), used only if a
photo can't load.

To use real photos instead, drop a file with the same key (`.jpg`, `.jpeg`, `.png` or `.webp`) next to them,
e.g. `south_indian.jpg` or `pizza.jpg`. Your own photos are picked before everything else.

Keys: south_indian, dosa, pizza, chai, kebab, tandoori, biryani, burger, restaurant,
dental, haircut, spa, salon, yoga, gym, pharmacy.

Keep each photo under ~300 KB (about 1200 px wide is plenty).
